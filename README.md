# Veerabhadra R – Portfolio

A one-page portfolio with SEO built in. No build step, no npm install needed.

## Files
- index.html   – the website
- 404.html     – page shown for wrong links
- favicon.svg  – the icon in the browser tab
- og-image.png – the picture shown when the link is shared
- robots.txt   – tells Google it may visit the site
- sitemap.xml  – list of pages for Google

## Before going live
Replace every `your-portfolio.vercel.app` with your real web address.
In VS Code: Ctrl+Shift+H, find `your-portfolio.vercel.app`, replace all.

## Run it on your computer
Double-click index.html, or in VS Code use the "Live Server" extension.
